# Soal 2 - Sedang

##  Deskripsi Program
Program ini berisi dua bagian:
1. Menghitung **faktorial** dari bilangan bulat positif.
2. Menghitung **volume tabung** menggunakan **fungsi dengan parameter**.

##  Cara Kerja Program
### Bagian 1 - Faktorial
1. Pengguna memasukkan bilangan bulat positif.
2. Program menggunakan **loop** untuk menghitung hasil faktorial (n! = n × (n-1) × ... × 1).
3. Hasil faktorial ditampilkan di layar.

### Bagian 2 - Volume Tabung
1. Pengguna memasukkan **jari-jari** dan **tinggi tabung**.
2. Program memanggil fungsi `hitungVolumeTabung(double r, double t)` yang menghitung volume dengan rumus: Volume = π × r² × t
