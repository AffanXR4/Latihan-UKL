# Soal 1 - Mudah

##  Deskripsi Program
Program ini memiliki dua fungsi utama:
1. Menghitung biaya pengiriman berdasarkan berat, jarak, dan volume barang.
2. Menentukan apakah suatu bilangan yang dimasukkan oleh pengguna merupakan bilangan **ganjil atau genap**.

##  Cara Kerja Program
1. Pengguna memasukkan data:
   - Berat paket (kg)
   - Jarak tempuh (km)
   - Panjang, lebar, dan tinggi (cm)
2. Program menghitung:
   - Biaya per kg (Rp 4.250 jika jarak ≤ 10 km, atau Rp 6.000 jika > 10 km)
   - Tambahan biaya Rp 50.000 jika volume > 100 cm³.
3. Program menampilkan total biaya pengiriman.
4. Setelah itu, program meminta pengguna memasukkan angka lain untuk dicek apakah **ganjil atau genap**.
