# Soal 3 - Sulit

##  Deskripsi Program
Program ini terdiri dari dua bagian utama:
1. Menghitung nilai rata-rata dari sejumlah nilai siswa.
2. Melakukan penjumlahan dua matriks yang diinput oleh pengguna.

##  Cara Kerja Program
### Bagian 1 - Rata-rata Nilai
1. Pengguna memasukkan jumlah siswa.
2. Kemudian pengguna memasukkan nilai ujian untuk setiap siswa.
3. Program menghitung total dan rata-rata nilai.
4. Hasil rata-rata ditampilkan.

### Bagian 2 - Penjumlahan Matriks
1. Pengguna menentukan ukuran matriks (baris dan kolom).
2. Pengguna memasukkan elemen-elemen untuk matriks A dan B.
3. Program menjumlahkan kedua matriks dan menampilkan hasilnya dalam bentuk matriks C.
